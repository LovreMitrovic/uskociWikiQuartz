# Bun (1330)

Vlach forebear named in the **1330 Dečanska povelja** (Stefan Uroš III's hrisovulja for manastir Dečani). Listed by name with sons **Nikola, Tvrtko, Tvrde, Tudorica**, brother **Rade**, and Rade's son **Vojisil** [[Saric-2008-Bunjevci]] (Ivanović 1951–52:260).

The clan **Bunovići** in the [[Tudoricevci]] katun (29 ognjišta) descends from him. Onomastic relic: **Bunova livada / Livadhi i Bon's** in selo Shaptej near Dečani (Gashi 1982).

Šarić takes the name **Bun/Bunj** to be a vlach personal name from Latin *Bonifacius* via Balkan-Romance vocalic shift *o > u*; this Bun is a key 14th-c. attestation of the anthroponym from which the etnik **Bunjevac** is derived.
